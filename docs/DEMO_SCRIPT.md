# Social-first demonstration

1. Run `npm run dev`, scan the terminal QR in SDK58 Expo Go. Returning sessions open Feed. New/signed-out users choose Log in or Explore demo. Do not reset the native demo; it contains the user's21garments.
2. Browse real photographic outfit/clothing posts. Sample community content is labeled fictional and licensed. Tap an outfit → Remix With My Closet: actual owned pieces, honest substitutions and missing-piece shopping.
3. Open a Clothing post → Find Similar. Meta understands its photo once; Discover receives its query/category/source-post context and shows real SerpApi listings. Cached results retain their last-checked timestamp. Offline sample demo is labeled and makes no provider calls.
4. Floating Style Me → choose Casual day → Generate with Meta → Try another. The actual displayed pieces change without switching occasion. Dinner/Classes/Date/Party use distinct styling priorities; limited closets get honest guidance. Save a look or share with an actual photo.
5. Closet → browse representative stock photos and the user's actual uploaded photos; All/Tops/Bottoms/Shoes. Photo/text/voice input and editing/deletion remain. No laundry/check-in clutter.
6. Feed → Create post → photo → Outfit or Clothing → optional caption/visibility → preview/publish. No wardrobe cataloguing required. New posts require photos; selected saved-outfit metadata is optional.
7. Feed header Messages → existing group/DM, normal text and photographic outfit/post previews. Sharing is not wearing. Profile → own/saved posts, saved outfits, Settings and seven-day planner.

Camera capture and real microphone recording remain user-only physical-device tests. Simulator gallery, actual Meta/Serp and keyboard/safe-area evidence are recorded in SOCIAL_FIRST_STATUS.md and docs/SIMULATOR_QA.md. No Jester features or manufactured real social activity.
